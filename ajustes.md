## Comunidades Virtuais
* São criadas vazias por um Admin da plataforma. 
* Cada Jogador deve estar vinculado a uma comunidade
* As trilhas devem possuir desafios relacionados a coleta de dados reais
* A medida que o jogador vai realizando a trilha e concluido os desafios referentes a sua comunidade, os dados gerados pelos mesmos passam a ser registrados de forma temporal na respectiva comunidade virtual e vinculados ao jogador responsável. estes dados passam a contar como pontuação do jogador , também de forma temporal, na medida que a coleta for interrompida, é interrompido também o computo de pontos. 
* Todos os dados coletados sobre a comunidade devem ser armazenados de forma permanente para avaliações e análises futuras, ainda que anonimizados quando necessário
